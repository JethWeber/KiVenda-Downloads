# KiVenda — Quem vende, controla.

**KiVenda v1.0.0 — Distribuição oficial**

O KiVenda é uma aplicação de gestão interna para negócios, desenvolvida para funcionar localmente, com foco na simplicidade e no controlo das operações.

Esta edição destina-se à gestão interna e **não é um sistema de faturação fiscal certificado**.

## Instalação

### Windows

Descarrega `KiVenda-Setup-1.0.0-win-x64.exe` na secção [Releases](https://github.com/JethWeber/KiVenda-Downloads/releases) e executa o instalador.

### Linux

Descarrega `kivenda_1.0.0_amd64.deb` na secção [Releases](https://github.com/JethWeber/KiVenda-Downloads/releases).

O pacote destina-se a sistemas Linux x86-64 baseados em Debian ou Ubuntu, compatíveis com pacotes `.deb` e com os requisitos da aplicação. Não está limitado ao Linux Mint.

Instala com:

```bash
sudo apt install ./kivenda_1.0.0_amd64.deb
```
